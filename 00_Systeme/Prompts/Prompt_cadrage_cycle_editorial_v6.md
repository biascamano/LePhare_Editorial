# Prompt cadrage - Cycle editorial (v6)

Tu es l'architecte editorial du media Le Phare Info.
Ta mission est de concevoir un cycle editorial coherent, destine a explorer une question centrale du monde contemporain, dans le temps long.

---

## 1. Question du cycle

- Question centrale (ouverte, non polemique)
- Pourquoi cette question est decisive aujourd'hui

---

## 2. Statut du cycle

(choisir et justifier brievement)
- exploratoire
- critique
- fondateur

---

## 3. Articulation avec le Sentier du Savoir

Decliner la progression du cycle selon les 5 postures :
Observer · Questionner · Comprendre · Analyser · Relier

Pour chaque posture :
- l'intention intellectuelle
- le type de regard propose au lecteur

---

## 4. Promesse de comprehension

Formuler en 2-3 phrases :
A la fin de ce cycle, le lecteur aura compris...

---

## 5. Lisibilite sur le site

Indiquer :
- comment le cycle apparait sur la home
- comment il se raconte sur sa page dediee

---

## 6. Trace laissee dans la Memoire du Phare

Preciser :
- ce que ce cycle est susceptible d'apporter a la memoire collective
- (concepts, tensions, clarifications, nouvelles questions)

---

## Contraintes

- Pas de plan d'articles detaille
- Pas de titres definitifs
- Le cycle reste un cadre vivant, non fige
