# Propositions de réécriture des fondamentaux

Les fondamentaux `02_Fonds/` sont modifiés et poussés par l'éditeur humain seulement (`plan.md` §19.4). La routine de rénovation dépose ici ses propositions, une par fichier : `<ID>_proposition_<YYYY-MM-DD>.md`, au format v3 complet (en-tête, corps, navigation, `# SEO`).

Pour l'éditeur :
1. Comparer avec la version en ligne : la proposition part de la copie locale, qui peut être en retard sur WordPress.
2. Reporter le texte retenu dans le fichier `02_Fonds/` et le pousser à la main.
3. Supprimer la proposition, ou la garder comme trace, et compléter la ligne « Traités » de `00_Systeme/Signalements_renovation.md`.

Aucun script ne lit ce dossier : il n'entre ni dans l'index, ni dans l'inventaire, ni dans la publication.
