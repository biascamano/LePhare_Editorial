# Checklist — création d’un compte officiel

Répéter pour chaque plateforme retenue.

## Avant création

- [ ] Handle / nom disponible (voir `01_Identite/bios-gabarits.md`)
- [ ] Email dédié ou alias pro (ex. contact@le-phare.info)
- [ ] Bio et lien site prêts
- [ ] Visuels (logo, bannière) exportés

## Création

- [ ] Compte **professionnel** ou **page** (pas compte perso mélangé)
- [ ] Bio collée + URL https://le-phare.info
- [ ] Photo de profil = logo
- [ ] Bannière si applicable
- [ ] **2FA** activée ; mots de passe dans coffre (Bitwarden, etc.)
- [ ] Accès partagé documenté (qui administre, qui publie)

## Juridique / transparence

- [ ] Mention « Le Phare Info » + lien association quand RNA connu
- [ ] Pas de promesse de reçu fiscal sur les RS tant que non sécurisé (dossier `conformite/` à la racine de Nexus des mondes)
- [ ] Politique : pas de cession de droits sur commentaires utilisateurs au-delà du nécessaire plateforme

## Premier contenu

- [ ] Post de lancement (présentation + lien vers un article pilier)
- [ ] Épingler / featured si la plateforme le permet
- [ ] Noter l’URL du profil dans `01_Identite/bios-gabarits.md`

## Sécurité

- [ ] Sauvegarder codes de récupération 2FA
- [ ] Ne pas stocker mots de passe en clair dans ce dépôt
