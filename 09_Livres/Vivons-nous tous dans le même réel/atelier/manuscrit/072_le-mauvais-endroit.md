# Chapitre 72

## Le mauvais endroit

Le jardin est immobile.

Ou du moins…

c’est l’impression qu’il donne.

Vous retrouvez le vieil homme devant le vieux chêne.

Vous vous asseyez sous ses branches.

Longtemps, aucun de vous ne parle.

Puis il vous demande, presque distraitement :

— Où est le jardin ?

Vous le regardez en souriant.

— Devant nous.

Il secoue doucement la tête.

— Vraiment ?

Vous désignez les arbres.

Les fleurs.

Le ruisseau.

Les oiseaux.

Les pierres.

— Il est là.

Le vieil homme ramasse une feuille.

Il la dépose dans votre main.

— Le jardin est-il dans cette feuille ?

— Non.

Il montre ensuite une racine qui affleure.

— Est-il dans cette racine ?

— Non.

Puis une pierre.

Puis une abeille.

Puis une goutte d’eau suspendue au bout d’une herbe.

Chaque fois, votre réponse est la même.

— Non.

Il vous regarde avec douceur.

— Alors…

où est-il ?

Vous restez silencieux.

Vous sentez que la question vous échappe.

Le jardin n’est dans aucun de ces éléments.

Et pourtant…

il existe.

Vous marchez lentement.

Vous regardez les arbres.

S’il ne restait qu’un seul arbre…

parlerait-on encore d’un jardin ?

Probablement pas.

S’il ne restait que la terre…

ni les oiseaux…

ni les fleurs…

ni le vent…

quelque chose manquerait.

Le jardin semble exister dans une manière très particulière.

Il n’est pas enfermé dans une chose.

Il apparaît lorsque beaucoup de choses vivent ensemble.

Le vieil homme reprend :

— Pendant très longtemps…

nous avons posé la même question à propos de l’esprit.

Où est-il ?

Dans quelle partie ?

Dans quelle cellule ?

Dans quel endroit précis ?

Vous l’écoutez sans bouger.

— C’était une bonne question.

Mais peut-être…

pas la bonne manière de regarder.

Vous repensez au violon.

À la musique.

À l’orchestre.

À la forêt.

Aux fourmis.

Au vieux chêne.

Toutes ces histoires semblent soudain converger.

Le vieil homme poursuit :

— Lorsque nous cherchons une mélodie…

nous ne démontons pas le violon.

Vous souriez.

L’image est si simple…

et pourtant si profonde.

— Nous écoutons ce qui apparaît lorsqu’il joue.

Le vent traverse doucement les branches.

Vous comprenez peu à peu.

Peut-être cherchons-nous parfois certaines réalités dans les objets…

alors qu’elles naissent entre eux.

Vous levez les yeux vers la canopée.

La lumière filtre entre les feuilles.

Aucune ne dessine seule ce paysage.

Pourtant…

ensemble…

elles créent quelque chose qu’aucune ne contient.

Le vieil homme se lève.

Avant de repartir, il pose une dernière question.

— Si tu voulais comprendre une forêt…

passerais-tu toute ta vie à étudier une seule feuille ?

Vous restez immobile.

Non.

Bien sûr que non.

Vous commenceriez par la feuille.

Puis la branche.

Puis l’arbre.

Puis les échanges entre les arbres.

Puis le sol.

Puis les champignons.

Puis les oiseaux.

Puis le climat.

Peu à peu…

la question changerait.

Vous ne demanderiez plus seulement :

*“De quoi est faite une forêt ?*

Vous demanderiez :

*“Comment une forêt devient-elle une forêt ?”*

Vous quittez le jardin lentement.

Une étrange sensation vous accompagne.

Depuis le début de vos promenades…

le vieil homme n’avait peut-être jamais cherché à répondre à vos questions.

Il essayait simplement…

de vous apprendre à poser de meilleures questions.
