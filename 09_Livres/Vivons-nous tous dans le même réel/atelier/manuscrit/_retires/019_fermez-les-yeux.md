# Chapitre 19

## Fermez les yeux

Vous restez debout.

Le jardin est maintenant plongé dans une pénombre douce.

Le dernier rouge du ciel s’efface lentement.

Vous inspirez profondément.

Puis, presque sans réfléchir, vous fermez les yeux.

Au début…

il ne se passe rien.

Seulement du noir.

Vous avez l’impression que le jardin disparaît.

Vous n’avez plus d’arbres.

Plus de fleurs.

Plus de sentier.

Comme si le monde venait de s’éteindre.

Pourtant…

quelques secondes passent.

Et quelque chose revient.

Une branche craque.

Très loin.

Vous ne savez pas où.

Puis un froissement de feuilles.

À votre gauche.

Ou peut-être un peu derrière.

Une légère brise touche votre joue.

Vous sentez aussitôt de quel côté elle vient.

Une odeur humide monte de la terre.

Elle n’était pas apparue.

Elle était déjà là.

Vous ne la remarquiez simplement pas.

Vous continuez à garder les yeux fermés.

Le silence d’il y a quelques minutes n’existe plus.

Il était rempli.

Vous ne l’entendiez pas.

Une goutte tombe d’une feuille.

Puis une autre.

Un insecte passe près de votre oreille.

Quelque part, une chouette pousse un cri bref.

Le jardin recommence à exister.

Autrement.

Vous comprenez alors que voir occupait une immense partie de votre attention.

Vos yeux étaient devenus des chefs d’orchestre.

En leur absence, les autres sens prennent timidement la parole.

Vous inspirez de nouveau.

Cette fois, vous distinguez presque les différentes odeurs.

La mousse.

La terre.

Le bois humide.

Une fleur encore ouverte.

Vous ouvrez lentement les yeux.

Étrangement…

le jardin vous paraît moins familier qu’avant de les fermer.

Comme si vous reveniez d’un voyage.

Vous regardez vos mains.

Elles sont les mêmes.

Le vieux chêne est toujours là.

Le sentier n’a pas bougé.

Et pourtant…

vous avez l’impression d’habiter un endroit différent.

Peut-être parce que vous venez de découvrir une chose très simple.

Voir n’est pas percevoir.

Voir…

n’est qu’une manière de percevoir.

Pendant toute votre vie, vous avez confondu les deux.

Cette confusion est si naturelle que vous ne l’aviez jamais remarquée.

Vous souriez.

Vous vous demandez alors une chose.

Si quelques secondes les yeux fermés suffisent à transformer un jardin…

Que se passerait-il…

…si vous pouviez emprunter les sens d’un autre être vivant ?
