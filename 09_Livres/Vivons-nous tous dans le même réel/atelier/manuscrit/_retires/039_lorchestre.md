# Chapitre 39

## L’orchestre

Le lendemain, le jardin est animé.

Le vent joue avec les branches.

Les insectes passent d’une fleur à l’autre.

Un merle saute entre les racines du vieux chêne.

Vous vous asseyez sans chercher à comprendre.

Vous regardez simplement.

Le merle s’envole.

Au même instant, plusieurs autres oiseaux quittent les arbres.

Comme si un signal invisible avait traversé le jardin.

Vous n’avez rien entendu.

Eux, oui.

Vous continuez à observer.

Une colonie de fourmis traverse le sentier.

L’une s’arrête.

Puis une autre.

Puis des dizaines changent légèrement de direction.

Aucune ne semble donner d’ordre.

Pourtant…

la colonne avance.

Vous repensez au vieux chêne.

Ses racines.

Ses feuilles.

Sa sève.

Aucune branche ne commande les autres.

Aucune feuille ne connaît l’arbre entier.

Et pourtant…

le chêne pousse.

Vous fermez les yeux.

Votre respiration continue.

Votre cœur bat.

Votre estomac travaille.

Vos oreilles captent les sons.

Votre peau sent la fraîcheur de l’air.

Des milliers d’événements se déroulent en vous.

Sans chef apparent.

Vous ouvrez les yeux.

Le jardin vous paraît soudain très différent.

Depuis votre arrivée, vous cherchiez toujours un centre.

Le chef.

Le conducteur.

Le décideur.

Vous découvrez aujourd’hui une autre possibilité.

Et si certaines choses existaient précisément…

parce que personne ne les dirigeait seul ?

Le vieil homme s’approche.

Il ne dit rien.

Il s’assoit à côté de vous.

Vous observez ensemble le jardin.

Après un long silence, il ramasse une brindille.

Il dessine un point dans la terre.

— Si tout dépend de ce point…

il suffit qu’il disparaisse pour que tout s’arrête.

Il efface le point.

Puis il dessine un cercle composé de centaines de petits points reliés entre eux.

— Mais si chacun participe un peu…

que devient le tout ?

Vous regardez le dessin.

Il ne ressemble à rien de particulier.

Et pourtant…

vous y reconnaissez le jardin.

L’arbre.

Les oiseaux.

Votre corps.

Peut-être même…

vos pensées.

Le vieil homme sourit.

— Nous avons longtemps cherché un roi caché.

Un pilote.

Un chef d’orchestre.

Puis certains chercheurs ont commencé à regarder autrement.

Ils se sont demandé si le véritable miracle ne venait pas…

des relations.

Il efface lentement son dessin.

— Les relations sont discrètes.

On ne les voit presque jamais.

On voit les feuilles.

Pas les échanges de sève.

On voit les oiseaux.

Pas les courants d’air qu’ils utilisent.

On voit les paroles.

Pas les liens qui les rendent possibles.

Vous restez longtemps immobile.

Une intuition prend forme.

Peut-être que votre vie entière repose sur quelque chose que vous observez rarement.

Non les choses.

Mais ce qui les relie.

Avant de repartir, vous regardez une dernière fois le vieux chêne.

Pour la première fois…

vous ne voyez plus un arbre.

Vous voyez une conversation.

Silencieuse.

Ininterrompue.

Vieille de plusieurs siècles.

Et vous comprenez soudain pourquoi le jardin vous semblait si vivant.

Ce n’était pas parce qu’il était rempli d’êtres.

C’était parce qu’il était rempli de relations.
