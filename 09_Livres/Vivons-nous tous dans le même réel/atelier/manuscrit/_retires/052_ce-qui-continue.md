# Chapitre 52

## Ce qui continue

Le lendemain, le jardin semble inchangé.

Et pourtant…

vous savez désormais qu’il ne l’est jamais.

Une fleur s’est fanée.

Une autre vient d’éclore.

Une branche est tombée.

Une mousse a gagné quelques centimètres.

Le changement est partout.

Mais il avance si lentement qu’il ressemble parfois à l’immobilité.

Vous retrouvez le vieil homme près du ruisseau.

Il lance une petite brindille dans le courant.

Vous la regardez s’éloigner.

Puis disparaître derrière les roseaux.

— Tu crois que le ruisseau est toujours le même ?

demande-t-il.

Vous regardez l’eau.

Elle coule sans interruption.

Aucune goutte n’est encore là où elle était quelques secondes plus tôt.

Et pourtant…

vous continuez à l’appeler “le ruisseau”.

Vous souriez.

Cette question vous rappelle d’autres promenades.

Le jardin semble aimer les choses qui changent sans cesser d’être elles-mêmes.

Le vieil homme ramasse une vieille pomme tombée au pied d’un arbre.

Elle est à moitié décomposée.

Des insectes s’y affairent.

Une odeur de terre humide s’en dégage.

— Beaucoup verraient ici une fin.

Il ouvre doucement le fruit.

Quelques graines sont encore intactes.

— Le jardin y voit surtout une transition.

Vous reprenez votre marche.

Vous observez les arbres.

Les plus vieux portent les traces des tempêtes.

Les plus jeunes profitent d’une trouée de lumière.

Les deux appartiennent au même jardin.

Mais aucun ne vit exactement la même histoire.

Le vieil homme s’arrête devant une jeune pousse.

Elle grandit au pied d’un immense chêne.

Vous vous demandez si elle parviendra un jour à atteindre la lumière.

Il semble deviner votre pensée.

— Peut-être.

Ou peut-être pas.

Puis il ajoute :

— Pendant longtemps, les hommes ont cru que le vivant avançait vers une forme idéale.

Comme si la nature poursuivait un but.

Il secoue doucement la tête.

— Le jardin ne cherche pas la perfection.

Il continue simplement à répondre au monde qui l’entoure.

Vous restez silencieux.

Cette phrase éclaire soudain beaucoup de choses.

Les oiseaux.

Les fleurs.

Les insectes.

Les arbres.

Tous changent.

Non pour devenir meilleurs.

Mais pour continuer à vivre dans un monde qui, lui aussi, change.

Le vieil homme s’accroupit.

Il trace deux lignes dans la terre.

La première est parfaitement droite.

La seconde ondule légèrement.

— Laquelle te semble la plus solide ?

Vous montrez instinctivement la ligne droite.

Il sourit.

Puis il souffle doucement sur le sable.

La ligne droite disparaît presque entièrement.

La ligne sinueuse, elle, est encore visible.

— Ce qui résiste n’est pas toujours ce qui est le plus rigide.

Parfois…

c’est ce qui sait se transformer.

Vous relevez les yeux.

Le vent recommence à jouer dans les branches.

Vous comprenez soudain pourquoi le jardin paraît si ancien.

Ce n’est pas parce qu’il ne change jamais.

C’est parce qu’il change…

sans jamais cesser de vivre.
