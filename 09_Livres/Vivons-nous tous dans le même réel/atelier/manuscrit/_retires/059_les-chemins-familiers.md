# Chapitre 59

## Les chemins familiers

Le lendemain, le ciel est couvert.

Le jardin paraît différent.

Vous empruntez un sentier que vous connaissez bien.

Du moins…

vous le pensez.

Vous avancez sans réfléchir.

Vos pas se succèdent naturellement.

À un croisement, le vieil homme vous demande :

— Pourquoi es-tu passé par ici ?

Vous le regardez, surpris.

— C’est le chemin.

Il sourit.

— Lequel ?

Vous désignez le sentier.

— Celui-ci.

Il secoue doucement la tête.

— Celui que tu empruntes souvent.

Pas forcément le seul.

Vous vous retournez.

À quelques mètres, un autre chemin serpentait derrière une haie.

Vous ne l’aviez même pas remarqué.

Pourtant…

il était bien là.

Le vieil homme reprend la marche.

— Le jardin est rempli de chemins.

Nos habitudes en effacent la plupart.

Vous avancez en silence.

Cette idée vous poursuit.

Vous repensez à toutes ces fois où vous étiez persuadé d’avoir observé attentivement…

avant de découvrir que vous aviez simplement regardé ce que vous attendiez.

Un merle surgit soudain d’un buisson.

Vous le suivez du regard.

Quelques secondes plus tard, le vieil homme vous montre un écureuil.

Vous ne l’aviez pas vu.

Puis un papillon.

Puis une fleur minuscule.

Puis une toile d’araignée couverte de rosée.

Le jardin semblait vide.

Il débordait pourtant de détails.

Le vieil homme s’accroupit.

— Notre regard aime les chemins déjà connus.

Ils demandent moins d’effort.

Vous pensez à vos certitudes.

À vos premières impressions.

Aux idées qui vous semblaient évidentes.

Combien d’entre elles étaient simplement…

des chemins familiers ?

Vous continuez à marcher.

Cette fois, beaucoup plus lentement.

À chaque détour, vous cherchez volontairement ce qui vous avait échappé.

Le jardin paraît soudain immense.

Comme si chaque promenade précédente n’en avait révélé qu’une petite partie.

Avant de quitter le sentier, le vieil homme s’arrête.

— Ce n’est pas parce qu’un chemin est familier qu’il est mauvais.

Il est simplement…

familier.

Il vous regarde avec bienveillance.

— Le plus difficile n’est pas d’apprendre un nouveau chemin.

C’est de remarquer que l’on marche toujours sur le même.

Vous restez immobile.

Le vent fait doucement bouger les branches.

Pour la première fois, vous vous demandez combien de chemins invisibles habitent votre manière de penser.

Et vous comprenez qu’ils sont peut-être plus nombreux que ceux du jardin lui-même.
