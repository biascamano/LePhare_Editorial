# Chapitre 61

## Les surprises

Le lendemain, le jardin semble paisible.

Rien ne paraît avoir changé.

Vous avancez tranquillement.

Vous connaissez maintenant ce sentier.

Vous savez où le ruisseau tourne.

Où le vieux chêne apparaît.

Où les merles aiment se poser.

Vous pourriez presque marcher les yeux fermés.

Le vieil homme vous observe en silence.

Puis il vous demande :

— Que penses-tu trouver derrière ce massif de fougères ?

Vous souriez.

— Le petit pont.

Vous contournez les fougères.

Le pont est bien là.

Vous poursuivez votre chemin.

Quelques minutes plus tard, il pose une nouvelle question.

— Et derrière cette haie ?

— Le banc.

Vous avancez.

Le banc est exactement à sa place.

Vous commencez à trouver ce jeu amusant.

Le jardin vous semble devenu prévisible.

Puis soudain…

au détour d’un chemin…

vous vous arrêtez net.

Le vieux banc a disparu.

À sa place se trouve un jeune arbre.

Vous regardez autour de vous.

Vous êtes certain de ne pas vous être trompé de sentier.

Le vieil homme ne dit rien.

Il attend.

Vous cherchez le banc du regard.

En vain.

Votre esprit hésite.

Avez-vous oublié ?

Était-il ailleurs ?

Vous revenez sur vos pas.

Puis vous apercevez enfin le banc.

Quelques mètres plus loin.

Les jardiniers l’ont simplement déplacé.

Vous éclatez de rire.

Le vieil homme aussi.

— Étrange, n’est-ce pas ?

Ce n’est pas le banc qui t’a surpris.

C’est ton attente.

Vous continuez votre marche.

Vous remarquez maintenant combien votre esprit anticipe sans cesse.

Au prochain virage…

vous vous attendez à voir le ruisseau.

Il apparaît.

Vous pensez entendre un rouge-gorge.

C’est bien lui.

Vous cherchez instinctivement le vieux saule.

Il est exactement là où vous l’imaginiez.

Vous comprenez alors que votre promenade est remplie de prédictions silencieuses.

La plupart sont si justes…

que vous ne les remarquez jamais.

Le vieil homme cueille une feuille.

Il la laisse tomber.

Le vent l’emporte dans une direction inattendue.

Vous la suivez des yeux.

— Voilà pourquoi les surprises sont précieuses.

Vous le regardez.

— Elles nous réveillent.

Il hoche doucement la tête.

— Elles montrent que le monde est plus riche que nos habitudes.

Vous restez pensif.

Toute votre vie, vous avez peut-être considéré les surprises comme des interruptions.

Et si elles étaient…

des invitations ?

Avant de quitter le jardin, vous vous retournez une dernière fois vers le banc déplacé.

Il n’a parcouru que quelques mètres.

Pourtant…

pendant quelques instants, il avait suffi à ébranler toutes vos certitudes.

Vous souriez.

Le jardin ne cherchait pas à vous tromper.

Il vous apprenait simplement que ce n’était pas lui qui était devenu imprévisible.

C’était vous qui étiez devenu trop sûr de le connaître.
