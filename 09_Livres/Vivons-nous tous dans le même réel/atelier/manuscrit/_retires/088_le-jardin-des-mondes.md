# Chapitre 88

## Le jardin des mondes

Le matin est clair.

Le jardin semble plus vaste que jamais.

Vous franchissez le portail avec une étrange sensation.

Comme si quelque chose s’achevait.

Et qu’autre chose commençait.

Le vieil homme vous attend au sommet d’une petite colline.

Pour la première fois, vous découvrez le jardin dans son ensemble.

Les chemins.

Les clairières.

Les mares.

Le verger.

Le vieux chêne.

La serre.

Les ruches.

Tout apparaît d’un seul regard.

Vous restez silencieux.

Le vieil homme demande :

— Est-ce le jardin ?

Vous répondez presque aussitôt.

— Oui.

Il sourit.

— Ou seulement ce que tu peux en voir d’ici ?

Vous restez immobile.

Vous comprenez immédiatement.

Depuis le premier jour, chaque lieu visité vous semblait être le jardin.

Aujourd’hui, vous découvrez qu’il existait toujours davantage.

Vous poursuivez votre marche jusqu’à une immense prairie.

Des dizaines d’êtres vivants s’y croisent.

Une abeille cherche des fleurs.

Un renard suit une piste invisible.

Une buse décrit de larges cercles dans le ciel.

Une taupe creuse sous vos pieds.

Des enfants jouent.

Une botaniste observe les orchidées.

Un peintre installe son chevalet.

Un musicien écoute le vent.

Tous occupent le même lieu.

Et pourtant…

vivent-ils dans le même monde ?

Le vieil homme reprend doucement.

— Chacun rencontre une partie différente du réel.

Aucun ne le possède entièrement.

Vous regardez la botaniste.

Elle remarque immédiatement une espèce rare.

Vous ne l’aviez même pas vue.

Le peintre, lui, contemple la lumière.

Le musicien ferme les yeux.

Il écoute ce que personne ne semble entendre.

Le renard poursuit une odeur.

L’abeille suit une couleur qui vous échappe.

Tous sont présents.

Tous sont sincères.

Tous décrivent un même jardin.

Et pourtant…

leurs jardins ne sont pas identiques.

Vous poursuivez votre marche.

Le vieil homme cueille une poignée de terre.

— Cette poignée contient des milliards d’organismes.

Vous n’en voyez aucun.

Pour eux…

ceci est un univers.

Vous laissez doucement la terre retomber.

Le jardin grandit encore.

Le nouvel interlocuteur vous rejoint.

Il observe la scène.

— Les cartes que nous construisons du monde deviennent de plus en plus précises.

Mais une carte n’est jamais le territoire.

Le vieil homme acquiesce.

— Et le territoire lui-même continue de changer.

Vous repensez à tout ce que vous avez découvert.

La perception.

L’Umwelt.

L’attention.

La mémoire.

Les émotions.

Les autres.

L’intelligence.

Tout semblait conduire ici.

Vous vous asseyez dans l’herbe.

Une question surgit presque d’elle-même.

— Alors…

vivons-nous tous dans le même réel ?

Le vieil homme laisse passer un long silence.

Puis il répond.

— Nous partageons un même univers.

Mais nous n’en habitons jamais exactement la même expérience.

Le nouvel interlocuteur ajoute :

— Et c’est peut-être une chance.

Vous le regardez.

— Pourquoi ?

— Parce que si chacun révélait exactement la même partie du monde…

personne ne découvrirait jamais rien de nouveau.

Le vent traverse la prairie.

Les hautes herbes ondulent.

Vous comprenez soudain que la diversité des regards n’est pas un obstacle à la connaissance.

Elle en est peut-être la condition.

Le vieil homme reprend.

— Nous passons parfois notre vie à vouloir convaincre les autres qu’ils devraient voir le monde comme nous.

Il désigne le jardin.

— Le jardin, lui…

semble préférer la diversité.

Vous observez une dernière fois la prairie.

Toutes ces formes de vie.

Toutes ces histoires.

Toutes ces manières d’exister.

Vous ne ressentez plus le besoin de savoir laquelle est la meilleure.

Vous ressentez simplement de la curiosité.

En quittant la colline, une phrase vous accompagne.

Le réel est peut-être infiniment plus vaste que chacun de nos mondes.

Et c’est précisément pour cette raison que nous avons tant besoin les uns des autres.
