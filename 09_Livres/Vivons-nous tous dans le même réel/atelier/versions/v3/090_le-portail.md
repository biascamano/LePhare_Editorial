# Chapitre 90

## Le portail

Vous avancez une dernière fois vers le portail.

La clé repose dans votre poche.

Le jardin est calme.

Le vieux chêne laisse danser ses feuilles dans la lumière.

Le ruisseau poursuit son chemin.

Les abeilles travaillent.

Le peintre termine sa toile.

Le musicien écoute le vent.

Les enfants rient près de la cabane.

Le nouvel interlocuteur discute avec une étudiante.

Le vieil homme est assis un peu plus loin.

Il ne vous regarde pas.

Il contemple simplement le jardin.

Vous comprenez.

Il n’y a plus rien à ajouter.

Vous vous approchez malgré tout.

— Une dernière question.

Le vieil homme tourne lentement la tête.

— Laquelle ?

Vous respirez profondément.

Cette question vous accompagne depuis le premier jour.

— Alors…

vivons-nous tous dans le même réel ?

Le vieil homme garde le silence.

Longtemps.

Puis il sourit.

— Qu’en penses-tu ?

Vous baissez les yeux.

Autrefois, cette réponse vous aurait déçu.

Aujourd’hui…

vous comprenez qu’elle est peut-être la seule possible.

Vous regardez une dernière fois le jardin.

L’abeille.

Le merle.

La mousse.

Le renard.

Le peintre.

Le scientifique.

L’enfant.

Le nouvel interlocuteur.

Le vieil homme.

Vous-même.

Tous habitent un même univers.

Tous rencontrent un monde différent.

Tous peuvent apprendre les uns des autres.

Vous relevez lentement la tête.

— Je crois…

que nous partageons un même réel.

Mais aucun de nous n’en possède la totalité.

Le vieil homme acquiesce doucement.

— Voilà pourquoi nous avons besoin des autres.

Vous ajoutez, presque sans réfléchir :

— Et voilà pourquoi nous avons besoin de rester curieux.

Le vieil homme sourit.

Cette fois…

il ne répond pas.

Vous vous dirigez vers le portail.

Vous glissez la clé dans la serrure.

Elle tourne sans effort.

La porte s’ouvre.

Vous franchissez le seuil.

Et soudain…

quelque chose vous surprend.

De l’autre côté, il n’y a pas un autre monde.

Il y a votre monde.

Une rue.

Des arbres.

Des oiseaux.

Une femme qui promène son chien.

Un enfant qui ramasse un caillou.

Un voisin qui arrose ses fleurs.

Le vent.

Le ciel.

Le bruit d’un train au loin.

Vous restez immobile.

Le jardin n’a pas disparu.

Il s’est agrandi.

Vous comprenez enfin.

Le jardin n’était jamais un endroit.

C’était une manière de regarder.

Vous avancez de quelques pas.

Chaque passant porte une histoire invisible.

Chaque arbre dialogue avec le sol.

Chaque oiseau habite un monde sensoriel différent du vôtre.

Chaque enfant découvre un univers que les adultes ont parfois cessé de voir.

Même les objets les plus ordinaires retrouvent une profondeur nouvelle.

Une tasse de café.

Une pierre.

Une goutte de pluie.

Un sourire.

Un silence.

Vous réalisez que le voyage ne vous a pas appris à quitter le réel.

Il vous a appris à le rencontrer.

Vous vous retournez une dernière fois.

Le portail est toujours là.

Entrebâillé.

Le vieil homme vous fait un signe discret.

Puis il reprend sa promenade.

Il ne disparaît pas.

Il continue simplement son chemin.

Comme vous allez continuer le vôtre.

Vous marchez désormais dans votre propre jardin.

À chaque rencontre.

À chaque question.

À chaque émerveillement.

Et vous comprenez enfin pourquoi le vieil homme ne vous a presque jamais donné de réponses.

Une réponse ferme souvent une porte.

Une bonne question ouvre un chemin.

Le monde n’est peut-être pas devenu plus simple.

Il est devenu plus vaste.

Plus vivant.

Plus mystérieux.

Vous souriez.

Puis vous reprenez votre route.

Le livre se referme.

Le jardin, lui…

reste ouvert.
