# Deuxième partie


# Chapitre 13

## Les certitudes

Vous reprenez le sentier.

Le jardin ne vous paraît plus inconnu.

Vous reconnaissez certains arbres.

Vous savez où le chemin tourne.

Vous retrouvez même, sans difficulté, le vieux banc de pierre.

Cette sensation vous rassure.

Vous avez l’impression de connaître les lieux.

Puis vous vous arrêtez.

Connaître…

Que signifie exactement ce mot ?

Vous regardez autour de vous.

Les mêmes fleurs sont là.

Les mêmes pierres.

Le même chêne.

Vous avez le sentiment que rien ne pourrait vous surprendre désormais.

À cet instant, un petit garçon apparaît au détour du chemin.

Il court.

S’arrête devant une flaque d’eau.

S’accroupit.

Il reste là, parfaitement immobile.

Vous vous approchez doucement.

Il ne regarde pas la flaque.

Il regarde ce qu’elle contient.

Un minuscule têtard.

Pour lui, le jardin entier vient de disparaître.

Il n’existe plus qu’une flaque.

Puis une femme arrive.

Elle l’appelle.

Le garçon ne répond pas.

Il continue d’observer.

Finalement, elle s’accroupit à son tour.

Quelques secondes passent.

Puis elle sourit.

Elle aussi vient de voir le têtard.

Vous poursuivez votre marche.

Cette scène ne vous quitte plus.

Vous étiez passé exactement au même endroit.

Vous n’aviez même pas remarqué la flaque.

Encore moins le têtard.

Pourtant, il était là.

Vous pensez alors à une phrase entendue un jour.

Nous ne voyons pas les choses telles qu’elles sont.

Nous les voyons telles que nous sommes.

Vous ignorez qui l’a prononcée.

Peut-être même qu’elle n’a jamais été dite ainsi.

Mais elle résonne étrangement avec votre promenade.

Depuis le début, le jardin ne cesse de vous montrer que chacun prélève dans le réel une poignée d’indices.

Puis construit son propre paysage.

L’enfant découvre un monde miniature.

Le jardinier remarque les plantes.

L’ornithologue entend des chants que vous ne distinguez pas.

Le chien suit des pistes invisibles.

L’abeille trouve des motifs cachés dans les fleurs.

Et vous…

Que choisissez-vous sans même le savoir ?

Cette question vous accompagne longtemps.

Peut-être passez-vous votre vie à regarder certains détails.

Toujours les mêmes.

Peut-être ignorez-vous systématiquement tout le reste.

Si c’est vrai…

Alors votre réalité ressemble peut-être davantage à une sélection…

…qu’à un reflet fidèle du monde.

Vous vous retournez une dernière fois vers la flaque.

Le petit garçon est toujours accroupi.

Le têtard nage tranquillement.

Le jardin continue d’offrir mille histoires à ceux qui prennent le temps de les voir.

Aucune n’est fausse.

Aucune n’est complète.

Et c’est peut-être cela qui rend ce lieu si fascinant.

Chaque regard y découvre un monde.

Sans jamais épuiser le réel.
