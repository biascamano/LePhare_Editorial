# Chapitre 56

## Le même arbre

Le lendemain, le vieil homme vous attend devant le vieux chêne.

Vous vous arrêtez à ses côtés.

Vous ne dites rien.

Vous connaissez désormais cet arbre.

Ou du moins…

vous le croyez.

Le vieil homme pose une main sur son écorce.

— Que vois-tu ?

Vous souriez.

Autrefois, la réponse aurait été simple.

Aujourd’hui…

elle semble impossible.

Vous observez.

Vous voyez un arbre.

Puis des branches.

Puis des feuilles.

Puis des insectes.

Puis des oiseaux.

Puis les mousses qui couvrent son tronc.

Puis les champignons à son pied.

Puis les racines invisibles.

Puis les graines qu’il produira.

Puis les arbres qui naîtront peut-être un jour de ces graines.

Vous gardez le silence.

Le vieil homme attend.

— Je ne vois plus seulement un arbre.

Il acquiesce.

— Moi non plus.

À cet instant, un petit garçon traverse le jardin.

Il s’arrête devant le chêne.

Ramasse un gland.

Le glisse dans sa poche.

Puis repart en courant.

Quelques minutes plus tard, une vieille femme vient s’asseoir contre le tronc.

Elle ferme les yeux.

Comme si elle retrouvait un vieil ami.

Plus tard encore, un jardinier passe.

Il observe les branches.

Le feuillage.

L’écorce.

Il repart après quelques secondes.

Tous ont vu le même arbre.

Ou presque.

Le vieil homme reprend :

— Lequel d’entre eux a vu le vrai chêne ?

Vous réfléchissez.

Puis vous secouez doucement la tête.

— Aucun.

Il sourit.

— Ou peut-être…

tous.

Vous sentez immédiatement que cette réponse n’est pas une pirouette.

Le petit garçon a rencontré un jeu.

La vieille femme, un souvenir.

Le jardinier, un organisme vivant.

Vous…

vous y voyez désormais un monde.

Le vieil homme ramasse le gland laissé au sol.

Il le fait tourner entre ses doigts.

— Les arbres ne changent pas seulement avec les saisons.

Ils changent aussi avec le regard qui les rencontre.

Vous restez longtemps silencieux.

Cette phrase éclaire soudain tout votre voyage.

Le chien.

L’abeille.

Le merle.

Les graines.

Darwin.

Le carnet.

Les idées.

Vous comprenez enfin ce qui les relie.

Aucun ne révélait la totalité du réel.

Chacun révélait une manière différente de l’habiter.

Le vent traverse les branches.

Vous écoutez leur bruissement.

Pour la première fois…

vous ne cherchez plus à savoir qui a raison.

Vous cherchez ce que chaque regard rend visible.

En quittant le jardin, vous vous retournez une dernière fois.

Le vieux chêne est toujours là.

Le même.

Et pourtant…

vous savez déjà que demain, vous ne le verrez plus tout à fait de la même façon.
