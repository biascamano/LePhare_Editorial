# Chapitre 57

## La passerelle

Ce matin-là, le jardin est plus animé que d’habitude.

Des enfants courent entre les arbres.

Deux jardiniers discutent près d’une haie.

Un couple marche lentement.

Un peintre installe son chevalet.

Vous vous asseyez sur un banc.

Sans le chercher, vous observez les autres.

Le vieil homme arrive.

Il ne regarde pas le jardin.

Il regarde les promeneurs.

— Que vois-tu ?

Vous répondez presque instinctivement.

— Des personnes.

Il secoue doucement la tête.

— Regarde encore.

Vous laissez passer quelques instants.

Le peintre s’arrête devant le vieux chêne.

Il ouvre sa boîte de couleurs.

À quelques mètres de lui, un botaniste examine les feuilles avec une loupe.

Un enfant ramasse des glands.

Un photographe cherche la lumière.

Tous sont immobiles.

Tous regardent le même arbre.

Et pourtant…

vous comprenez qu’aucun d’eux ne voit exactement la même chose.

Le vieil homme murmure :

— Étrange, n’est-ce pas ?

Ils habitent le même jardin.

Mais pas tout à fait le même monde.

Vous observez encore.

Le peintre échange quelques mots avec le botaniste.

Ils sourient.

Le botaniste montre une feuille.

Le peintre montre la lumière qui la traverse.

L’enfant s’approche.

Il pose une question.

Le photographe leur montre une image sur son appareil.

Pendant quelques minutes, chacun apporte quelque chose que les autres n’avaient pas vu.

Vous sentez une idée prendre forme.

Le jardin ne leur demande pas de voir tous la même chose.

Il leur permet de partager ce qu’ils voient.

Le vieil homme reprend doucement :

— Si chacun devait percevoir exactement le même monde…

nous n’aurions probablement rien à nous raconter.

Vous laissez cette phrase résonner.

Elle renverse une évidence.

Depuis le début, vous cherchiez ce qui nous séparait.

Vous découvrez que nos différences sont peut-être aussi ce qui rend la rencontre possible.

Vous regardez de nouveau le petit groupe.

Le peintre repart avec une meilleure connaissance de l’arbre.

Le botaniste repart avec une nouvelle façon de regarder la lumière.

L’enfant repart avec une poignée de glands…

et beaucoup de questions.

Le photographe emporte une image.

Personne n’a abandonné son regard.

Pourtant…

chacun est reparti un peu différent.

Avant de quitter le jardin, vous vous retournez.

Le vieux chêne est toujours au centre.

Mais aujourd’hui…

ce n’est plus l’arbre qui attire votre attention.

C’est ce qui circule entre les personnes qui le regardent.

Vous comprenez alors qu’un jardin n’est peut-être pas seulement un lieu où poussent des arbres.

C’est aussi un lieu où poussent des regards.
