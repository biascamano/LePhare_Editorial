# Chapitre 10

## L’ombre

Le soleil est maintenant haut dans le ciel.

Les ombres se sont raccourcies.

Vous avancez lentement entre deux massifs d’arbustes.

Le jardin paraît paisible.

Presque immobile.

Soudain…

quelque chose bouge.

Sur le côté du sentier.

Vous vous arrêtez net.

Pendant une fraction de seconde, vous êtes persuadé qu’un animal vient de traverser devant vous.

Votre cœur accélère légèrement.

Vous tournez la tête.

Rien.

Seulement une branche qui oscille doucement.

Le vent s’est levé.

Vous restez immobile.

Ce qui vous surprend n’est pas de vous être trompé.

C’est la certitude que vous aviez ressentie.

Pendant un instant, il n’y avait aucun doute.

Vous aviez vu quelque chose.

Ou, plus exactement…

vous aviez cru le voir.

Vous reprenez votre marche.

Quelques mètres plus loin, le même phénomène se reproduit.

Une ombre glisse rapidement sur le sol.

Vous levez les yeux.

Cette fois, vous apercevez le véritable responsable.

Un nuage vient de passer devant le soleil.

Le paysage entier a changé de lumière pendant une seconde.

Votre esprit avait immédiatement cherché une explication.

Un animal.

Une présence.

Un mouvement.

Vous souriez.

Cette réaction est probablement bien plus ancienne que vous.

Pendant des centaines de milliers d’années, hésiter devant une ombre pouvait coûter quelques secondes.

Ne pas réagir face à un prédateur pouvait coûter la vie.

Dans le doute, il valait mieux imaginer un danger.

Quitte à se tromper.

Vous continuez votre promenade.

À présent, vous observez davantage votre propre regard que le jardin.

Chaque mouvement attire votre attention.

Chaque changement de lumière.

Chaque bruissement.

Vous commencez à remarquer quelque chose d’étrange.

Votre regard n’attend jamais.

Il anticipe.

Avant même que vous compreniez une scène, une première interprétation apparaît déjà.

Comme si quelqu’un, en vous, cherchait en permanence à terminer les images avant qu’elles ne soient complètement arrivées.

Vous vous arrêtez devant un vieux saule.

Ses longues branches descendent presque jusqu’au sol.

Le vent les fait onduler lentement.

Pendant quelques secondes, elles prennent l’apparence de silhouettes.

Puis cette impression disparaît.

Les branches redeviennent des branches.

Vous vous demandez combien de fois, dans votre vie, vous avez confondu une ombre avec une réalité.

Pas seulement dans ce jardin.

Dans une conversation.

Dans un regard.

Dans une intention.

Dans une peur.

Combien de fois votre première impression s’est-elle révélée inexacte ?

Le jardin ne répond pas.

Il laisse simplement le vent jouer avec les feuilles.

Vous reprenez votre marche.

Le sentier semble identique à celui du matin.

Pourtant, une nouvelle idée s’est installée.

Voir n’est pas seulement recevoir des images.

C’est aussi deviner.

Et parfois…

nos suppositions arrivent avant les faits.

Le vieux chêne apparaît de nouveau au bout du chemin.

Vous le regardez différemment.

Depuis votre arrivée, il n’a jamais changé.

Pourtant, votre manière de le voir ne cesse d’évoluer.

Peut-être que le jardin ne vous apprend pas seulement à regarder le monde.

Peut-être vous apprend-il aussi…

…à vous méfier de vos certitudes.
