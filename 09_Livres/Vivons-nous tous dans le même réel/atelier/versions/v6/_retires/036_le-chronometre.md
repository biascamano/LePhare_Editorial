# Chapitre 36

## Le chronomètre

Le lendemain, le jardin est presque vide.

Le vent s’est arrêté.

Même les oiseaux semblent attendre.

Vous vous asseyez sur un vieux banc.

Pour la première fois depuis votre arrivée, vous décidez…

de ne rien décider.

Vous observez simplement.

Une feuille tombe.

Vous la suivez des yeux.

Votre main se lève.

Sans raison particulière.

Juste pour la rattraper.

Vous la manquez.

Vous souriez.

Pourquoi votre main s’est-elle levée ?

Vous cherchez une réponse.

Aucune ne vient.

Quelques instants plus tard, vous changez de position.

Puis vous croisez les jambes.

Puis vous grattez votre joue.

Puis vous regardez le ciel.

Toutes ces décisions paraissent minuscules.

Elles semblent pourtant surgir d’elles-mêmes.

Vous essayez un jeu.

Vous vous dites :

« Dans quelques secondes, je lèverai un doigt. »

Vous attendez.

Pas encore.

Toujours pas.

Maintenant.

Votre doigt bouge.

Mais une question étrange apparaît immédiatement.

À quel moment avez-vous vraiment décidé ?

Lorsque vous avez pensé :

« Maintenant » ?

Ou quelques instants avant ?

Vous recommencez plusieurs fois.

Chaque essai vous laisse la même impression.

La décision semble apparaître…

comme si elle venait de quelque part que vous ne voyez pas.

Le vieil homme arrive discrètement.

Cette fois, il porte un petit chronomètre ancien.

Il le fait tourner dans sa main.

— Pendant très longtemps, cette question est restée philosophique.

Il marque une pause.

— Puis un homme a eu une idée étrange.

Pourquoi ne pas essayer de la mesurer ?

Vous le regardez.

— Mesurer une décision ?

Il acquiesce.

— Oui.

Demander à des volontaires de bouger un doigt quand ils le souhaitent.

Puis comparer trois instants.

Le moment où leur cerveau semble se préparer.

Le moment où ils disent avoir décidé.

Et le mouvement lui-même.

Le vieil homme referme doucement le chronomètre.

— Les résultats ont surpris tout le monde.

Vous attendez la suite.

Il sourit.

Mais ne répond pas.

À la place, il vous tend le chronomètre.

— Avant de connaître le résultat…

que pensez-vous qu’il se passe ?

Vous restez silencieux.

Pour la première fois depuis le début du voyage…

vous avez envie de formuler votre propre hypothèse.

Le vieil homme semble satisfait.

— C’est toujours une bonne idée de réfléchir…

avant de regarder la réponse.

Vous repartez.

Le chronomètre pèse doucement dans votre poche.

Vous ne savez toujours pas comment naissent vos décisions.

Mais désormais…

vous savez qu’elles peuvent être observées.

Et lorsqu’une question devient observable…

elle entre dans un nouveau jardin.

Celui de la science.
